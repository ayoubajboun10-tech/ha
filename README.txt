KHADIJA — THE MAGICAL JOURNEY (A Journey Beyond the Ordinary)
==============================================================

HOW TO RUN
1. Extract the ZIP anywhere.
2. Double-click index.html (Chrome, Edge, Firefox or Safari). No install, no server, no internet needed.
   Optional: run "python3 -m http.server" in this folder and open http://localhost:8000

HOW TO PLAY
- Press "Bda l-mo8amara" to start. Click "Kmel" to continue dialogue; click glowing objects to collect them.
- Top-right: backpack (inventory) and menu (music / sound volume, reduce motion, resume).
- Progress is saved automatically in your browser; use "Kmel" on the menu to continue later.
- Audio starts only after you press Start.

PUBLISH ON GITHUB PAGES
Upload all files (index.html at the root) to a repo, then Settings > Pages > Deploy from branch (main / root).

FILES
index.html, style.css, script.js (story, dialogue, quests, inventory, puzzles, audio, saving, rendering),
assets/icons/moon.svg. Characters, scenery and all audio are generated in code (SVG, CSS, Web Audio), so there are no image, font or sound files to go missing.

STORY TEXT: edit the C array in script.js.
