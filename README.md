# Happy Khadija — The Magical Birthday Journey
Vanilla HTML/CSS/JS, no build step, no backend. Characters, scenery and audio are generated in code (SVG, CSS, Web Audio).

## Run locally
Open `index.html` in a browser (or `python3 -m http.server` and visit http://localhost:8000).

## Publish on GitHub Pages
1. Create a repo and upload all files (keep `index.html` at the root).
2. Settings → Pages → Deploy from branch → `main` / root → Save.
3. Your site appears at `https://<user>.github.io/<repo>/`.

## Notes
- Languages: Darija (Latin), العربية (RTL), English — switch live from the top bar.
- Music/volume/reduced-motion controls are in the top bar; audio only starts after the first click.
- Edit story text in the `C` array in `script.js`.
